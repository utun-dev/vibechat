# auto_socket

Модуль согласует локальные endpoint с интерфейсами ОС (`auto_sockets=yes`) либо новым списком
`[server]` от frontend (`auto_sockets=android`). `auto_socket_protocols` выбирает UDP, TCP или оба.
Public API и изменения транспортов выполняются в uasync; повторный активный init — ошибка.
`init` возвращает 0/-1, полный отказ запуска освобождает собственные ресурсы.

## Системные интерфейсы

Полное сканирование собирает до 64 UP-интерфейсов без loopback, затем сверяет каждый.
После успешного получения списка удаляются записи исчезнувших/DOWN-интерфейсов;
ошибка получения или превышение лимита не интерпретируется как пустая сеть.
IPv4 определяется по адресам интерфейса, IPv6 исключает ::/loopback/multicast/link-local;
ULA даёт NAT, глобальный unicast 2000::/3 — PUBLIC. На Linux при наличии постоянного IPv6
пропускаются temporary-адреса из /proc/net/if_inet6; без постоянного допускается временный.
FreeBSD/Windows не используют этот Linux-файл. Опционально семейство исключается при отсутствии default route.
Если маршрут нельзя прочитать, фильтр допускает интерфейс с WARN/диагностикой причины.

Сверка обходит IPv4/IPv6 × UDP/TCP. Каждая запись хранит собственные указатели endpoint/listener,
без повторного поиска произвольного сокета по family. При потере адреса/отключении протокола endpoint удаляется.
Смена IP или типа пересоздаёт endpoint; для UDP сравнивается фактический local_addr,
для TCP — объявленный IP при создании listener: STCP слушает wildcard выбранного семейства.
Поэтому предварительное обновление interface_addr монитором не скрывает смену адреса.
Неизменный endpoint сохраняется. При отказе замены слот остаётся NULL, очередное сканирование повторит создание.
Runtime-сверка может завершиться частично; начальная неполная сверка возвращает -1 и откатывает запуск.

Новый endpoint добавляется к допустимым NCD-транспортам через общие правила NCD.
Неполное добавление линков логируется, сам готовый endpoint остаётся доступным.
Изменения вызывают обновление настроенных core transports, Connection Manager групп,
CHAT_EVT_LOCAL_SOCKETS и при улучшении доступности/смене адресов — повтор чат-подключений.
Наличие семейства считается доступным только при ненулевом interface IP, probe_only исключён.

## Порты и остановка

SQLite `auto_socket_ports` хранит `(if_name, family, protocol)` и порт/updated_at.
protocol — 0 для UDP, 1 для TCP; family — native AF_INET/AF_INET6.
Сначала используется сохранённый целочисленный порт 1024..65535; некорректная строка даёт WARN.
При занятом порте выбирается случайный из того же диапазона, до 10 попыток после сохранённого.
Отказ RNG останавливает создание. Чтение/запись/удаление проверяют SQLite prepare/bind/step;
INSERT атомарен сам по себе, незавершённый SAVEPOINT не создаётся. Ошибка сохранения не закрывает рабочий endpoint.

При исчезновении интерфейса/отключении семейства его кеш портов удаляется.
При destroy endpoint/listener и линки закрываются, кеш остаётся для следующего init.
Модуль не удаляет чужие конфигурационные сокеты в системном режиме.
Список системных интерфейсов пуст в Android-режиме: конфигурационные endpoint освобождает ядро.

## Уведомления и потоки

Linux использует NETLINK_ROUTE с проверками sender/длин, FreeBSD — префикс PF_ROUTE
сообщений адресов/интерфейсов/маршрутов, Windows — IP Helper.
Неудачная регистрация/неблокирующий режим откатывают native socket.
Переполнение/усечение netlink вызывает полное сканирование с WARN.
FreeBSD-таблица маршрутов разбирается с native long alignment и границами каждой sockaddr,
включая сокращённую нулевую маску; адресный dump и маршруты проверяются до чтения полей.

IP Helper и `auto_socket_on_network_change` публикуют одну отменяемую задачу полного сканирования.
Её указатель защищён mutex/critical section. Перед destroy внешние вызывающие должны закончить свои вызовы;
жизнь instance/ua сама по себе не разрешает гонку с освобождением состояния модуля.
Stop запрещает новые публикации, завершает native callbacks и отменяет pending task до free.
При отказе Windows CancelMibChangeNotify2 отключённый callback context сохраняется с ERROR,
не обращаясь больше к instance/ua. Destroy нельзя вызывать из callback сверки.

## Android reload

`auto_socket_reload_config` принимает владение новым конфигом, переносит только servers,
остальное освобождает; остальные настройки текущего instance не заменяются.
Тип пересчитывается из IP. Endpoint сравнивается по имени, адресу/порту, transport/типу и параметрам bind;
port=0 сохраняет уже выбранный порт. Изменение MTU, mark/FIB, netif, SOCKS/REALITY/only_local или IPv6 policy
пересоздаёт соответствующий endpoint. probe_only остаётся нетронутым.
Заимствованные CFG_CLIENT_LINK.local_srv переназначаются на новый список до освобождения старого;
при исчезновении сервера сохраняется его имя для явного отказа дальнейшей привязки.
Обновление не транзакционно: при отказе новые servers остаются текущими, ошибка логируется.

## Проверки

`test_auto_socket_faults`: отказ замены UDP и восстановление, сохранение портов при stop,
отмена pending scan, удаление исчезнувшего интерфейса, отказ SQLite без открытой транзакции,
ошибка RNG, частичный запуск TCP/UDP и сохранность чужого endpoint.
`test_auto_socket_dynamic`: настоящие интерфейсы в Linux network namespace, три режима
TCP/UDP для IPv4/IPv6, многократная смена/удаление IPv4 при передаче и очистка timers/sockets.
`test_tun_route` покрывает также Android reload и перенос TUN-маршрутов.
