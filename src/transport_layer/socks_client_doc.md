# socks_client

SOCKS5 control-клиент для TCP CONNECT и UDP ASSOCIATE. Состояние принадлежит одному uasync-потоку;
cfg копируется, строки host/user/pass должны иметь NUL в массиве по 64 байта, port ненулевой.
Пустой user предлагает no-auth, непустой — no-auth и username/password (метод выбирает прокси).
Пароли не логируются. Имя самого прокси разрешается синхронным `getaddrinfo`, берётся первый IPv4/IPv6 адрес.
Это не общий асинхронный DNS-клиент; CONNECT target-domain передаётся прокси без локального резолвинга.

## CONNECT

`socks_dial(ua,cfg,target_host,target_port,cb,arg,timeout_tb)` принимает имя 1..255 байт без обрезания
и ненулевой target port. Числовой IP кодируется как ATYP 1/4, домен — ATYP 3.
Возврат NULL означает немедленный отказ без callback, возвращённый handle можно отменить через socks_dial_cancel.
timeout_tb задаёт общий connect+handshake срок в 0.1мс; <=0 означает 10 секунд.
Nonblocking, uasync-регистрация и таймер обязательны; отказ запуска откатывает ресурсы.
Даже немедленный успех connect продолжает handshake только после возврата конструктора.

Control читает ровно текущую рамку: greeting/auth по 2 байта, reply по ATYP и длине адреса.
Проверяются VER/RSV/REP/ATYP. Данные TCP-потока после CONNECT reply остаются в сокете,
в том числе когда пришли одним TCP-чтением ОС с ответом прокси.
Отправка подавляет SIGPIPE, повторяет EINTR, ждёт writable при EAGAIN; нулевой send даёт EPIPE.
Полная очередь управления не заменяется новой рамкой.

Завершение освобождает dial до cb. Успех передаёт владельцу незарегистрированный nonblocking socket,
ошибка закрывает его и передаёт SOCKET_INVALID/errno, WSA или протокольный код.
Handle после завершения недействителен; отменять его из callback нельзя. Cancel не вызывает cb.

## UDP ASSOCIATE

`socks_udp_associate` заимствует уже созданный local_udp_fd, держит отдельный TCP-control и relay.
На каждую попытку отводится 10 секунд. Разрыв/протокольная ошибка очищают ready, закрывают control
и планируют backoff 1,2,4,8,16,30,30... секунд. Успех сбрасывает backoff.
Начальная ошибка connect может вернуть handle с ожидающим retry; при невозможности поставить
как начальную работу, так и retry возвращается NULL без callback.

Relay поддерживает только числовой IPv4/IPv6 и ненулевой BND.PORT.
Wildcard BND.ADDR заменяется IP TCP-прокси того же семейства с сохранением BND.PORT.
Callback err=0 приходит при каждом успешном согласовании, включая повторное.
Если после запуска невозможно выделить retry timer, callback получает ENOMEM;
сессия остаётся unready, владелец должен destroy/recreate. В callback можно уничтожить сессию.
Остальные control-ошибки с успешной постановкой reconnect видны в proxy-логе.
Неожиданные данные на готовом control игнорируются с WARN.

`socks_udp_sendto` принимает 0..2048 байт, оборачивает в RSV=0/FRAG=0/ATYP/address/port
и отправляет через заимствованный UDP fd на relay. Успех возвращает длину данных без заголовка,
включая 0 для пустой датаграммы; -1 означает ошибку/не готово. DST только IPv4/IPv6.
Проверка длины выполняется до сложения/копирования; частичная отправка датаграммы считается ошибкой.

`socks_udp_unwrap` не использует s (допускается NULL), проверяет RSV/FRAG/ATYP и длины.
IPv4/IPv6 возвращают src и payload; domain/фрагменты не поддерживаются.
Возврат -1 сохраняет src/payload, 0 означает корректную пустую датаграмму.
Payload можно сдвигать в том же буфере, src должен быть отдельным. Вместимость требуется для полного payload.
Функция не проверяет адрес UDP-отправителя: caller должен принимать данные своего relay,
если не полагается на последующую аутентификацию транспорта.

Destroy снимает control/таймеры и освобождает состояние, local_udp_fd остаётся у владельца.
Все этапы/отказы видны в категории proxy; ожидание ready на send — trace.

`test_socks_client` покрывает no-auth/auth, доменное назначение, reject, UDP echo/reconnect,
CONNECT reply вместе с первым TCP-баннером, неверный RSV, startup/retry timer faults,
синхронно завершённый connect с нулевым send, destroy из ready, пустой UDP,
границы конфигурации/длины и неизменность выходов при отказе.
