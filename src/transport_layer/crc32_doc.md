# crc32

## 1. Назначение
Модуль вычисления контрольной суммы **CRC-32 (IEEE 802.3)** с отражённым полиномом `0xEDB88320`. Используется в подсистемах `secure_channel` и `stcp` для контроля целостности данных при передаче — перед шифрованием к данным добавляется CRC32, при расшифровке CRC32 пересчитывается и сверяется. `stun_nat` также использует результат для поля FINGERPRINT с дополнительным XOR `0x5354554e`.

Общая изменяемая таблица инициализируется без синхронизации. Перед первым параллельным использованием
нужно вызвать `crc32_init()` в одном потоке, завершив инициализацию до запуска остальных;
после этого вычисления только читают таблицу. Динамических выделений и логирования нет.

## 2. Как пользоваться

**Одноразовое вычисление (внутренне инициализирует таблицу при первом вызове):**
```c
// Для непустого блока: исходное значение UINT32_MAX, в конце побитовая инверсия
uint32_t crc = crc32_calc(data, data_len);
```

**Инкрементальное вычисление (например, при получении данных фрагментами):**
```c
uint32_t crc = 0xFFFFFFFF;
while (chunk) {
    crc = crc32_update(crc, chunk_data, chunk_len);
}
crc ^= 0xFFFFFFFF;  // финальный XOR
```

Для пустого потока этот пример даёт 0. В отличие от него, `crc32_calc(NULL, len)` и
`crc32_calc(data, 0)` возвращают `UINT32_MAX`: это особенность API, а не стандартный CRC пустого блока.

**С произвольным начальным значением (без финального XOR):**
```c
uint32_t crc = crc32_calc_ex(data, len, initial_crc);
```

## 3. API

| Функция | Описание |
|---------|----------|
| `crc32_init()` | Инициализация lookup-таблицы (256 × uint32_t). Повторный вызов ничего не меняет. Для однопоточного использования достаточно автоинициализации; для многопоточного нужна предварительная инициализация. |
| `crc32_calc(data, len)` | CRC32 «в один проход». Авто-инит, начальное значение `0xFFFFFFFF`, финальный `~crc`. При `data == NULL` или `len == 0` возвращает `0xFFFFFFFF`. |
| `crc32_calc_ex(data, len, initial_crc)` | CRC32 с заданным начальным значением, **без** финального XOR. При `data == NULL` или `len == 0` возвращает `initial_crc`; иначе обрабатывает ровно `len` байт. |
| `crc32_update(crc, data, len)` | Эквивалент `crc32_calc_ex(data, len, crc)` — инкрементальное обновление. |
