VibeChat — Ubuntu 26.04 x64, системные библиотеки

Распакуйте архив и выполните:
    bash install.sh --check
    bash install.sh

Скрипт проверяет версии пакетов, загрузку библиотек и обязательные Qt-плагины.
При нехватке пакетов выводит команду APT. Сам пакеты не устанавливает и sudo не запускает.
Нужен включённый репозиторий Ubuntu universe. Другие ОС этим выпуском не поддерживаются.

Программа: ~/.local/opt/vibechat/bin/vibechat
Запуск: через значок VibeChat в меню приложений или по указанному пути.
Повторная установка обновляет программу. Перед обновлением/удалением закройте VibeChat.
Профиль хранится отдельно в XDG-каталоге приложения; установщик его не меняет.
Удаление: bash ~/.local/opt/vibechat/uninstall.sh

Библиотеки устанавливаются отдельно администратором. Установщику права root не нужны.
